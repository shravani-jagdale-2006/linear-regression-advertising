# Linear Regression - Advertising Sales Prediction

## About the Project

This project uses Linear Regression to analyze the relationship between advertising expenditure and sales.

The dataset contains advertising expenditure on:
- TV
- Radio
- Newspaper

The goal is to build a Linear Regression model that predicts Sales based on advertising expenditure.

## Objective

- Understand the relationship between advertising expenditure and sales
- Perform exploratory data analysis
- Build a Linear Regression model
- Make predictions
- Evaluate the model performance

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Workflow

1. Load the dataset
2. Understand the dataset
3. Perform data analysis
4. Visualize relationships between variables
5. Select features and target
6. Split data into training and testing sets
7. Train Linear Regression model
8. Make predictions
9. Evaluate the model

## Model Evaluation

The model was evaluated using:

- R² Score
- Adjusted R²
- Mean Absolute Error
- Mean Squared Error

## Project Files

- `LR_Advertising_Sales.ipynb` - Complete Google Colab notebook
- `Advertising Budget and Sales.csv` - Dataset used for the project
